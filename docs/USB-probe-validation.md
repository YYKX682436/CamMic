# USB 免码探针记录（阶段②-1）

本文原记录的是阶段②-1的临时 Debug 探针，已被阶段②-2正式 USB 连接组件取代。这里仅保留背景说明，不能作为当前安装步骤，也不代表当前自动发现、Release 构建或真机验证结果。

阶段②-1已在 iPhone XR / iOS 14.3 上验证 USB 回环、免码 TLS-PSK、实际 PCM、Wi-Fi 隔离、会话密钥轮换和拔线静音。详细观察、工具版本、数据边界及本地保留的录音证据见[阶段②-1真机记录](validation/USB-XR-iOS14.3-2026-10-26.md)。该次验证使用了手动 `iproxy`，因此不能替代本阶段的 Mac 自动 USB 发现和打包验证。

阶段②-2采用用户确认的安全边界：不做 CamMic 应用级 Mac 身份认证或首次指纹确认；每轮 iPhone 采音生成临时 32 字节密钥，经 USB 回环初始化通道交给 Mac，再用于现有 TLS-PSK 音频连接。停止采音后会话失效。USB 专用端口与 Mac 本地转发入口只绑定 `127.0.0.1`，USB 不回退到 Wi-Fi。

这不认证具体 Mac 进程。能访问该可信 USB 转发路径或 iPhone 本机回环端口的其他进程，可能在采音期间取得临时密钥。既有可信主机验证、`idevicepair validate` 预检查、或 USB 连接成功，都不能证明所有未信任主机无法访问自定义端口。

当前用户安装和使用步骤见[安装与使用](安装与使用.md)。阶段②-2的 Release 构建、CI 和 XR 实测状态由交付回复明确报告。
