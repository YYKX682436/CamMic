# CamMic 快速安装与使用

CamMic 把 iPhone 麦克风作为 Mac 可选的系统输入设备。当前只有麦克风功能，没有摄像头功能。USB 是默认连接方式，无需 CamMic 配对码、Homebrew 或终端命令。

## 下载

从 [main 上成功的 0.6.0 beta CI 工作流](https://github.com/YYKX682436/CamMic/actions/workflows/ios14-ipa.yml?query=branch%3Amain%20is%3Asuccess) 下载：

- `CamMic-iOS14-unsigned.ipa`
- `CamMic-macOS-arm64.zip`
- `SHA256SUMS`

最低系统版本是 iOS 14.0 和 Apple silicon Mac 上的 macOS 13.0。最低部署版本不表示每个 iOS 14+ 机型都经过实测；本次候选版的具体验证设备见[测试版说明](releases/0.6.0-beta1.md)。

## 安装两端

### Mac

1. 解压 `CamMic-macOS-arm64.zip`，双击唯一的主安装器 `CamMic-Installer.pkg`，按 macOS 提示输入管理员密码。
2. 安装只替换 `/Applications/CamMic.app` 和 CamMic 自己的 HAL 驱动。安装驱动时 CoreAudio 会短暂重启，先停止正在录音的应用。
3. 如果 macOS 阻止打开未签名安装器，在 Finder 中按住 Control 点击安装器并选“打开”，或仅对 CamMic 在“系统设置 → 隐私与安全性”中允许打开。不要关闭系统整体安全保护。
4. 打开 CamMic。若状态提示音频组件未就绪，点“安装或修复 CamMic 麦克风”或“检查音频组件”。

应用、安装器和驱动未使用 Developer ID 签名或公证；驱动和应用带本地 ad-hoc 签名，安装包未签名。

### iPhone

`CamMic-iOS14-unsigned.ipa` 未签名。用 TrollStore 安装，或使用你已有的 iPhone 签名方式。首次启动时允许麦克风权限。更新时直接覆盖安装，**不要先卸载 CamMic，也不要清除应用数据**。

## 四步连接

1. **安装双端**：Mac 打开 `CamMic-Installer.pkg`；iPhone 安装 IPA。
2. **iPhone 开始采音**：打开 CamMic，点“开始 USB 采音”。开始采音后可以锁屏；电话、Siri 或其他应用占用麦克风时，iOS 可能中断采音。
3. **插入 USB**：连接数据线。若系统询问是否信任这台电脑，按系统提示操作并解锁 iPhone。Mac 会自动发现并连接；不需要输入配对码或 IP。
4. **Mac 选择 CamMic**：在 QuickTime Player 选“文件 → 新建音频录制”，打开输入菜单并选 **CamMic**。QuickTime 可能请求麦克风权限。选择录音输入不会改变 Mac 扬声器输出。

如果连接多台手机，可在 Mac CamMic 窗口选择设备。关闭主窗口不会断开连接；点菜单栏 CamMic 可重新打开窗口。菜单栏可点“静音 / 取消静音”“停止连接 / 恢复连接”；选“退出 CamMic”才会退出程序。

## 更新、修复和卸载

- **更新 iPhone**：在现有签名工具中覆盖安装新 IPA，不清除应用数据。
- **更新 Mac**：再次打开 `CamMic-Installer.pkg`。安装器会备份并替换已识别的 CamMic app 与驱动；不会替换其他音频驱动。安装失败会尝试恢复旧版本；若安装在回滚完成前中断，保留的恢复状态可由 ZIP 中的 `restore-cammic-install.sh` 恢复。
- **修复驱动**：应用窗口中点“安装或修复 CamMic 麦克风”，或使用 ZIP 内“可选工具”文件夹中的驱动修复包。
- **卸载**：运行 ZIP 内“可选工具/uninstall-cammic.sh”。它只移除已识别的 CamMic app、驱动和收据；不会删除 BlackHole、其他音频驱动或恢复备份。

## 无法连接时

- 确认 iPhone CamMic 显示正在采音，且数据线支持数据传输。
- 手动停止过连接时，在 Mac 选择“恢复连接”；拔插 USB 后自动重试。
- 若 Mac 提示音频组件未就绪，点“检查音频组件”或运行驱动修复工具。
- 在 QuickTime 等录音应用自己的输入菜单中选择 CamMic。系统输入默认设备与录音应用选择是两项设置。
