# CamMic 安装与使用

CamMic 让 iPhone 麦克风成为 Mac 可选的 **CamMic** 输入设备。USB 是默认连接方式，不需要输入配对码或在 Mac 上运行命令。

## 安装 Mac 版

1. 下载与本版本对应的 `CamMic-macOS-arm64-<提交号>.zip`，解压后打开 `CamMic-Installer.pkg`。
2. 按安装器提示完成安装并输入 Mac 管理员密码。安装音频组件时，macOS 音频服务会短暂重启；请先停止正在录音的应用。
3. 打开“CamMic”。如果 macOS 阻止打开未签名的下载内容，按系统提示在“系统设置 → 隐私与安全性”中允许打开。
4. 在“系统设置 → 声音 → 输入”中选择 **CamMic**，或者直接在 QuickTime 等录音应用的输入菜单中选择 **CamMic**。扬声器输出不会被更改。

## 安装 iPhone 版

`CamMic-iOS14-unsigned.ipa` 需要使用你现有的 iPhone 签名与安装方式处理。安装或更新时不要清除 CamMic 的应用数据。首次启动时允许 CamMic 使用麦克风。应用最低支持 iOS 14；阶段②-1的 USB 回环基础协议已在 iOS 14.3 上真机验证。

## 通过 USB 使用

1. 打开 iPhone 上的 CamMic，点 **开始 USB 采音**，并让 CamMic 保持在前台。
2. 用数据线把 iPhone 连接到运行 CamMic 的 Mac。若 iPhone 询问是否信任这台电脑，请按系统提示操作并解锁手机。
3. Mac CamMic 会自动发现并连接 iPhone。如果连接了多台 iPhone，在 Mac 窗口选择要使用的设备。连接成功后，录音应用选择 **CamMic** 即可录制 iPhone 麦克风声音。
4. 在 Mac CamMic 点 **静音** 可暂时静音；点 **停止并静音** 会结束连接并清除旧声音。再次连接需要点 **连接 iPhone**。

USB 连接不需要 Homebrew、`iproxy`、终端命令、IP 地址或 CamMic 配对码。首次系统信任和麦克风权限由 iOS/macOS 自己提示。

## 可选的 Wi-Fi 连接

在 Mac 与 iPhone CamMic 的 **高级选项** 中选择 Wi-Fi。该方式需要在同一局域网内手动填写 iPhone IP 地址和当前显示的 8 位配对码。默认 USB 使用不到这些信息。

## 无法连接时

- 确认 iPhone CamMic 正在采音，且手机保持解锁并处于前台。
- 检查数据线和 USB 连接；拔插后 CamMic 会自动重试。
- 若 Mac 显示音频组件未就绪，重新运行 `CamMic-Installer.pkg`，然后点“检查音频组件”。
- 若连接曾被手动停止，在 Mac CamMic 点 **连接 iPhone** 恢复。

CamMic 不保存 USB 会话密钥，也不会把密钥写入日志。为免码连接所需的临时密钥只在本次 iPhone 采音期间有效。当前设计不验证 Mac 上具体的 CamMic 进程；能访问该 USB 通道或 iPhone 本机回环端口的其他进程，可能在采音期间读取临时密钥。USB 专用 iPhone 端口和 Mac 转发入口只监听 `127.0.0.1`，不会通过 Wi-Fi 提供服务。`idevicepair validate` 一类预检查不能证明所有未经信任的主机都无法访问自定义端口。

## 许可与源码

CamMic 和音频驱动按 GPL-3.0 提供。Mac App 同时附带 libusbmuxd、libimobiledevice-glue、libplist 的 LGPL 许可文本与对应源码压缩包。完整的 CamMic 源码包、依赖源码及许可证均包含在 Mac 压缩包和 `CamMic.app/Contents/Resources/` 中。USB 连接不要求安装 Homebrew、`iproxy` 或其他外部 USB 命令行程序。
