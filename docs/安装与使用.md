# CamMic 安装与使用

CamMic 让 iPhone 麦克风成为 Mac 可选的 **CamMic** 输入设备。USB 是默认连接方式，不需要输入配对码或在 Mac 上运行命令。

## 安装 Mac 版

1. 下载与本版本对应的 `CamMic-macOS-arm64-<提交号>.zip`，解压后打开 `CamMic-Installer.pkg`。
2. 按安装器提示完成安装并输入 Mac 管理员密码。安装音频组件时，macOS 音频服务会短暂重启；请先停止正在录音的应用。
3. 打开“CamMic”。主窗口关闭后，CamMic 会继续在菜单栏运行；点击菜单栏 CamMic 可重新打开窗口。菜单栏的“停止连接”会静音并释放当前 USB 转发端口；只有选择“退出 CamMic”才会退出应用并释放 USBMux 订阅。如果 macOS 阻止打开未签名的下载内容，按系统提示在“系统设置 → 隐私与安全性”中允许打开。
4. 在“系统设置 → 声音 → 输入”中选择 **CamMic**，或者直接在 QuickTime 等录音应用的输入菜单中选择 **CamMic**。扬声器输出不会被更改。

## 安装 iPhone 版

在支持的系统上已安装 TrollStore：把 `CamMic-iOS14-unsigned.ipa` 保存到 iPhone，在 TrollStore 中打开并安装。更新时直接覆盖安装，不要先卸载 CamMic，也不要清除应用数据。

没有 TrollStore 时，这份 IPA 未签名，需要使用你已有的 iPhone 签名方式签名后安装；压缩包不包含证书或签名服务。首次启动时允许 CamMic 使用麦克风。应用最低支持 iOS 14。

## 通过 USB 使用

1. 打开 iPhone 上的 CamMic，点 **开始 USB 采音**。开始后可以按电源键锁屏、等待屏幕自然休眠或切换到其他 App；iOS 会按后台音频机制保持当前录音。屏幕仍可正常休眠。
2. 用数据线把 iPhone 连接到运行 CamMic 的 Mac。若 iPhone 询问是否信任这台电脑，请按系统提示操作并解锁手机。
3. Mac CamMic 会自动发现并连接 iPhone。如果连接了多台 iPhone，在 Mac 窗口选择要使用的设备。连接成功后，录音应用选择 **CamMic** 即可录制 iPhone 麦克风声音。
4. 在 Mac 窗口或菜单栏可以静音、取消静音、停止或恢复连接。停止连接会清除旧音频并暂停自动重连；只有明确选择恢复连接才会重新连接。关闭 Mac 主窗口不会影响当前连接。

电话、Siri 或其他应用抢占麦克风时，iOS 会中断录音，Mac 会静音并清空旧音频。系统明确允许恢复时 CamMic 会重建采集；如果系统不允许自动恢复，可回到 CamMic 点 **恢复采音**。手动停止 iPhone 采音后，切换前后台或迟到的系统通知都不会重新启动它。用户强制结束应用、系统终止应用或手机重启后，CamMic 不会自行启动采音。

USB 连接不需要 Homebrew、`iproxy`、终端命令、IP 地址或 CamMic 配对码。首次系统信任和麦克风权限由 iOS/macOS 自己提示。

## 可选的 Wi-Fi 连接

在 Mac 与 iPhone CamMic 的 **高级选项** 中选择 Wi-Fi。该方式需要在同一局域网内手动填写 iPhone IP 地址和当前显示的 8 位配对码。默认 USB 使用不到这些信息。

## 无法连接时

- 确认 iPhone CamMic 显示正在采音。锁屏期间通话或其他音频会话可能中断录音；回到 CamMic 查看中断状态，必要时手动恢复。
- 检查数据线和 USB 连接；拔插后 CamMic 会自动重试。
- 若 Mac 显示音频组件未就绪，重新运行 `CamMic-Installer.pkg`，然后点“检查音频组件”。
- 若连接曾被手动停止，在 Mac CamMic 点 **连接 iPhone** 恢复。

USB 会话密钥只在本次采音期间有效。CamMic 不验证 Mac 上具体的应用进程；能访问受信任 USB 通道或 iPhone 本机回环端口的其他进程，可能在采音期间读取临时密钥。完整安全边界、依赖许可和源码说明见压缩包中的 `README.md` 与 `THIRD_PARTY_NOTICES.md`。

## 许可与源码

CamMic 和音频驱动按 GPL-3.0 提供。Mac App 同时附带 libusbmuxd、libimobiledevice-glue、libplist 的 LGPL 许可文本与对应源码压缩包。完整的 CamMic 源码包、依赖源码及许可证均包含在 Mac 压缩包和 `CamMic.app/Contents/Resources/` 中。USB 连接不要求安装 Homebrew、`iproxy` 或其他外部 USB 命令行程序。
